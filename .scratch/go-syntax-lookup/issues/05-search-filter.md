# 05: 搜索过滤

**What to build:**

详情页顶部一个搜索框，输入即时过滤条目，不匹配的分组自动隐藏。匹配标题、说明、注意事项，不匹配代码正文——代码里到处是 `for`、`err`、`string`，搜代码正文出来的全是噪音。

**Blocked by:** 02 详情页最小链路

- [ ] 详情页内嵌一份 JSON payload，含全部条目的可搜索字段
- [ ] 输入关键词后即时过滤，不匹配的条目隐藏
- [ ] 匹配范围是标题、说明、注意事项；代码正文不参与匹配
- [ ] 某个分组下一条都不剩时，整个分组隐藏
- [ ] 过滤完全在浏览器端完成，服务端不做任何过滤或搜索
- [ ] payload 里的条目数量与页面渲染出来的条目数量一致
