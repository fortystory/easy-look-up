# 10: README

**What to build:**

一份 README，让三个月后的你还记得怎么把它跑起来、怎么加一条内容。内容站的长期维护成本几乎全在「怎么加内容」这件事上——它必须写得能被照着做。

**Blocked by:** 09 样式与响应式

- [ ] 写明项目是什么、怎么跑起来
- [ ] 写明目录结构，每部分负责什么
- [ ] 写明「怎么加一条内容」的完整步骤，含内容文件的字段说明
- [ ] 写明怎么跑测试
- [ ] 代码块示例里的注释用中文，符合项目的语言约定
