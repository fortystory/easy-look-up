# 13: Go 后端面试题分类

**What to build:**

把 Go 后端面试常问的问题收集成站内的七个新类别，形式是问答型条目：标题写成面试官会问的问句，答案是分点的要点。

七类：

- `interview-go`：语言基础与陷阱、运行时与调度器、内存与 GC、并发原语、常用标准库、性能分析与优化、工具链与工程实践、语言设计与规范
- `interview-concurrency`：性能指标与压测、高并发架构设计、并发问题排查、分布式并发、服务治理、高并发场景设计题
- `interview-gin`：路由与中间件、请求解析与参数绑定、响应与错误处理、工程实践与性能
- `interview-mysql`：索引与存储结构、事务与隔离级别、锁、查询优化、存储引擎与日志、高可用与运维
- `interview-redis`：数据结构与底层实现、持久化与高可用、缓存设计与常见问题、分布式锁与一致性、性能与运维
- `interview-web`：HTTP 协议、浏览器与页面渲染、Web 前端性能、Web 安全、API 设计与后端接口
- `interview-network`：TCP 与可靠传输、Socket 与 IO 模型、DNS 与 TLS、网络问题排查

**Blocked by:** 04 内容批量：Go 语法、常见错误、标准库、Gin
