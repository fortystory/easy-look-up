# 03: 类别页

**What to build:**

首页列出所有可查阅的类别，每类一张卡片链到对应详情页。v1 只有 Go 一个类别，但路由和数据模型按「任意多个类别」设计——将来加新类别只加内容，不改结构。

**Blocked by:** 02 详情页最小链路

- [ ] `GET /` 返回 200，列出所有类别
- [ ] 每个类别给出名称和链接，链接指向该类别的详情页
- [ ] 类别列表由内容目录的实际结构推导，不是硬编码
- [ ] 未知路径返回 404
- [ ] HTTP 层测试：首页返回 200，响应体含 Go 类别的链接，且该链接指向详情页
