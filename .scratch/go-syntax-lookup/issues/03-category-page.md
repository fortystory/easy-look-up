# 03: 类别页

**What to build:**

首页列出所有可查阅的类别，每类一张卡片链到对应详情页。路由和数据模型按「任意多个类别」设计——加新类别只加内容，不改结构。

**Blocked by:** 02 详情页最小链路

- [x] `GET /` 返回 200，列出所有类别
- [x] 每个类别给出名称和链接，链接指向该类别的详情页
- [x] 类别列表由内容目录的实际结构推导，不是硬编码
- [x] 未知路径返回 404
- [x] HTTP 层测试：首页返回 200，响应体含类别的名称、链接和分组/条目数量，且链接指向详情页
