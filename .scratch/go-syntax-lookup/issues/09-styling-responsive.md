# 09: 样式与响应式

**What to build:**

手写一个 CSS 文件，让页面像个能用的东西：浅色配色、代码块和页面背景有明确区分、窄屏手机上能读。不引 CSS 框架，不引 CDN——整个前端只有这一个样式文件加一小段原生 JavaScript。

**Blocked by:** 03 类别页, 05 搜索过滤, 06 复制按钮, 07 锚点导航与分组全展开

- [ ] 样式集中在一个 CSS 文件里，不引框架、不引 CDN
- [ ] 浅色配色，代码块与页面背景有明确区分
- [ ] 窄屏（手机宽度）下代码块不撑破页面，可在代码块内部横向滚动
- [ ] 复制按钮和锚点导航在手机上可点击，触控目标足够大
- [ ] 页面本身不出现横向滚动条（代码块内部滚动除外）
