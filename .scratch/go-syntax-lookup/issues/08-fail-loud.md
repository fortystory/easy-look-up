# 08: 失败要响亮

**What to build:**

内容写错时服务起不来，而不是上线一个内容残缺的站。用户访问不存在的地址时得到一个 404 页面，而不是空白。

这一片的主题是「宁可停下，也不要假装没事」。

**Blocked by:** 02 详情页最小链路

- [ ] 内容 JSON 非法时，服务启动即 panic 退出，错误信息指出出错的文件
- [ ] 内容字段缺失（比如缺 title）同样导致启动失败，不做静默默认值
- [ ] 未知路径返回 404 状态码
- [ ] 内容层测试覆盖 panic 路径，断言错误信息里含文件名
- [ ] HTTP 层测试覆盖 404 路径
