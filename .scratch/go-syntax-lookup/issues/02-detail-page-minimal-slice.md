# 02: 详情页最小链路

**What to build:**

从内容文件到浏览器的一条完整窄路径。服务启动时读内容目录、解析出分组和条目，`/go` 渲染出详情页：分组标题、每条的标题、说明，以及经过语法高亮的代码块。

这一片同时把两个测试 seam 立起来：内容加载层和 HTTP 请求层。

**Blocked by:** 01 内容样板：基本类型与变量

- [ ] 内容包定义表示类别、分组、条目的结构，能读出内容目录下 Go 类别的全部分组文件
- [ ] 内容在服务启动时一次性解析进内存，请求期间不再读文件
- [ ] 解析失败时服务启动即 panic，错误信息指得出是哪个文件
- [ ] `GET /go` 返回 200，页面含分组标题、每条的标题和说明
- [ ] 代码块由 chroma 在服务端高亮，输出的是高亮后的 HTML 而不是原始代码
- [ ] 内容层测试：合法内容解析出正确的分组与条目；非法内容 panic 且错误信息含文件名
- [ ] HTTP 层测试：`/go` 返回 200，响应体含分组标题和条目标题
- [ ] 一条命令能启动服务，默认端口 8080
